### Capstone Project Poster

Our final capstone poster presents a visual and technical overview of both the **R1D4 Hospital Delivery Robot Interface** and the **HoverBot Computer Vision Navigation System**, developed as part of ECSE 458D1/D2 at McGill University.

The poster highlights:

- **R1D4 Hospital Delivery Robot:** Android application screenshots, delivery management functionality, ESP32 communication and system architecture.
- **HoverBot Navigation System:** Computer vision-based robot tracking, position and orientation estimation, navigation demonstrations and integration with the existing TCP server.
- **Engineering Contributions:** Key development activities, hardware-software integration, technical challenges and project outcomes.

The poster was presented as part of our final capstone project and summarizes the collaborative engineering work completed by our four-member team.
